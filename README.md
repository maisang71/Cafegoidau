## 🌟 Giới thiệu dự án
**Cafe Gội Đầu Phúc Xuyên** là mã nguồn website giới thiệu dịch vụ và đặt lịch trực tuyến, kết hợp độc đáo giữa không gian thưởng thức cafe thư giãn và dịch vụ gội đầu dưỡng sinh thảo dược. 

Giao diện được thiết kế theo phong cách **Modern Minimalist & Glassmorphism 5.0**, tối ưu hóa hoàn toàn cho thiết bị di động, giúp lập trình viên dễ dàng chỉnh sửa và chạy trực tiếp trên các ứng dụng code mobile như **Acode** hoặc **Trebedit**.

---

## 🚀 Tính năng nổi bật
* **Responsive 100%:** Tối ưu hóa trải nghiệm hiển thị từ màn hình điện thoại nhỏ gọn đến máy tính bảng.
* **Thanh điều hướng linh hoạt:** Hỗ trợ cả Navbar phía trên (cho Desktop) và Bottom Navigation (cho Mobile).
* **Hiệu ứng mượt mà:** Sử dụng hiệu ứng làm mờ (`backdrop-filter`) và chuyển động hover tinh tế.
* **Form đặt lịch trực tuyến:** Tích hợp tính năng nhận thông tin khách hàng nhanh chóng.
* **Single-File Architecture:** Toàn bộ HTML, CSS và JavaScript được gom gọn trong một file `index.html` duy nhất, cực kỳ dễ quản lý trên điện thoại.
